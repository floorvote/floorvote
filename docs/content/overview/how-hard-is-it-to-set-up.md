# How hard is it to set up?

Setting up FloorVote is a technical task. You'll be provisioning Cloudflare resources and running deploy scripts, not clicking through a simple signup form. Take a look at the [Self-hosting guide](/self-hosting/) to see exactly what's involved before you commit — it walks through every step in order, so there's no guesswork about what comes next.

That said, it's manageable, not daunting:

- If you have a teammate who's comfortable with the command line, setup should go smoothly.
- If the guide looks intimidating on your own, an artificial intelligence coding agent such as Claude Code can carry most of the setup for you.
- Still stuck? [Reach out to us](https://floorvote.org/#contact) and we might be able to help get you started.
